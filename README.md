# 🎵 Dual-Variant Music Recommendation System

🚀 **[Live Demo](https://music-recommendation-app-wmvz5zgemzwmmxvmkyzvhh.streamlit.app/)**

An interactive music recommendation application built with **Python, SQL, MySQL, and Streamlit**, featuring two recommendation approaches and an intuitive web-based interface.

## 🎯 Project Overview

This project implements a music recommendation system that allows users to discover songs based on their preferences and interact with recommendations through a web application.

The system combines **SQL-based recommendation logic** with an interactive **Streamlit interface**, providing users with a simple way to explore and discover music.

## ✨ Features

* 🎵 Interactive music discovery and recommendation
* 🔎 Search and filtering functionality
* 📊 SQL-based ranking and recommendation logic
* 🎧 In-browser song playback
* 🖥️ Interactive Streamlit web application
* ☁️ Cloud-hosted MySQL database using Aiven
* 🚀 Deployed using Streamlit Community Cloud

## 🛠️ Technologies

* **SQL / MySQL**

## 💻 Run Locally

### 1. Clone the repository

```bash
git clone [YOUR_GITHUB_REPOSITORY_URL](https://github.com/Shreyashree-Mondal/music-recommendation-app/edit/main/README.md)
cd music-recommendation-app
```

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

### 3. Configure database credentials

Created the required Streamlit secrets/environment configuration for my MySQL database.

### 4. Run the application

```bash
dbmt_project_frontend_cloud.py
```
